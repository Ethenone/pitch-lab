# 绿茵阵容实验室

[打开在线网页](https://ethenone.github.io/pitch-lab/)

[下载 Windows 桌面版](https://github.com/Ethenone/pitch-lab/releases/download/v1.0.0/PitchLab-1.0.0-Windows-x64.exe) · [版本与使用说明](https://github.com/Ethenone/pitch-lab/releases/tag/v1.0.0)

桌面版支持 Windows 64 位，免安装、可离线使用。网页和桌面版的资料独立保存，可通过“导出资料 / 导入资料”迁移。

根据球员评分、位置资格、国家、曾效力球队和三人组合，寻找合适的首发与替补阵容。

## 游戏规则

### 阵容与球员

- 最终阵容由 **11 名首发 + 7 名替补**组成。
- 首发球员必须符合所在位置的资格；替补不限位置。
- 同一球员可以有不同评分版本，各版本共享姓名、国籍、位置和球队资料。
- 同一球员的不同版本不能重复入选；比赛模式中，各位置选出的人也必须互不相同。
- 球员可以有多个曾效力球队，分别参与各球队的人数统计；同时只触发一个球队的化学反应。

### 同球队、同国家加成

每支球队、每个国家先按人数计算达到的最高档位。球队加成只取所有球队中的最高一项，不叠加；并列最高时只计其中一支球队。

| 首发人数 | 替补人数 | 化学反应 |
| --- | --- | --- |
| 6–7 人 | 不限 | +20 |
| 8–10 人 | 不限 | +30 |
| 11 人 | 0–1 人 | +40 |
| 11 人 | 2–3 人 | +60 |
| 11 人 | 4–6 人 | +80 |
| 11 人 | 7 人 | +100 |

### 三人组合加成

每个组合由三名不同球员组成，按姓名匹配。

| 首发人数 | 替补人数 | 化学反应 |
| --- | --- | --- |
| 1 人 | 2 人 | +5 |
| 2 人 | 1 人 | +10 |
| 3 人 | 0 人 | +20 |

最高的一项球队加成、国家和三人组合加成相加后，**化学反应上限为 100**。

### 评分档位与最终分数

**最终分数 = 首发总评分 + 化学反应 ×（1 + 评分档位加成）**

| 首发总评分 | 档位加成 |
| --- | --- |
| 990 以下 | 0% |
| 990–994 | 30% |
| 995–1000 | 45% |
| 1001–1005 | 60% |
| 1006–1011 | 80% |
| 1012–1016 | 100% |
| 1017–1022 | 125% |
| 1023–1027 | 150% |
| 1028–1033 | 180% |
| 1034–1038 | 210% |
| 1039–1044 | 245% |
| 1045–1049 | 280% |
| 1050–1055 | 320% |
| 1056–1060 | 360% |
| 1061–1066 | 405% |

更高评分继续按同一规律计算：档位门槛交替增加 5、6 分，加成的增量按 +15、+15、+20、+20、+25、+25……递增。

例如，首发总评分为 1050、化学反应为 100 时，最终分数为 **1050 + 100 × 4.2 = 1470**。

## 功能介绍

### 普通模式

- 从资料库搜索并添加候选，也可以直接新建球员。
- 至少添加 19 名不同球员后，选择阵型并计算首发与替补方案。
- 可切换“最终分数”“化学优先”“评分优先”三种优化目标。

### 比赛模式

- 自由指定 11 个首发位置，也可以套用阵型模板后调整。
- 设置 7 个替补位置，并按需要增加预备队位置。
- 每个位置提供 1–5 名候选，计算时从每个位置选择 1 人，再按位置资格调整最终首发、替补和预备队。
- 搜索不到球员时，可以直接创建并加入当前位置；点击已有候选可查看、修改资料。
- “随机填满空位”从资料库补充候选，首发候选必须符合位置要求。
- “一键清空候选”清空所有位置的候选与计算结果，保留位置设置和球员资料。

### 球员与组合管理

- 添加、编辑、删除球员，以及同一球员的不同评分版本。
- 国家、球队支持选择已有条目，也支持输入新条目。
- 添加或编辑球员时，输入姓名即可查看相关三人组合，并继续添加组合。
- 组合成员尚未录入资料库时，也可以先按姓名建立组合。

### 计算结果

- 展示最终分数、首发总评分、化学反应，以及首发和替补名单。
- 点击球队、国家或组合加成，可查看贡献该项加成的球员。
- 比赛模式会在候选列表标明最终去向，高亮首发及参与化学反应加成的替补。

### 关联分析

- 球队共享球员网络与矩阵。
- 可踢位置关联、国家与球队关联。
- 球员、球队和位置聚类。

### 数据保存与导入导出

- 首次打开自动载入默认球员、组合和比赛位置。
- 玩家的修改保存在自己的浏览器中，不会影响其他玩家。
- 支持导出 JSON 备份；换浏览器或清除浏览器数据前，可先导出保存。
- 导入时可选择“合并导入”或“替换全部”：合并添加球员版本和组合，替换则使用备份中的完整资料与位置设置。

## 搜索算法

两种算法都在设置的时间内寻找更好的方案，展示的是**当前找到的最佳结果，不保证全局最优**。

### 模拟退火

适用于普通模式和比赛模式。

从一个可行阵容出发，不断尝试更换球员、交换位置等调整。搜索初期允许以一定概率接受较差方案，以便跳出当前局部最优；随着搜索进行，逐渐减少这类尝试，并保留过程中找到的最佳结果。

可设置：

- **搜索时长**：默认 5 秒。
- **探索强度**：默认 1 倍；越高越容易暂时接受较差方案。
- **重新生成起点的间隔**：默认每 7000 次调整；设为 0 可关闭。

### 目标引导分层搜索

适用于比赛模式。

1. 根据各位置候选，筛选有机会达到至少 6 人加成的球队、国家目标。
2. 围绕这些目标生成和调整候选名单；球队和国家用于引导搜索，不是必须满足的限制。
3. 确定一份 18 人名单后，精确比较其中可行的首发 11 人组合，其余 7 人作为替补。
4. 有预备队位置时，也会尝试让预备队球员进入最终 18 人名单。

固定 18 人后的首发与替补分配可以精确求解；在不同名单之间的整体搜索仍受时间限制。

可设置：

- **搜索时长**。
- **最多考虑的球队／国家目标数**：默认 24 个。
