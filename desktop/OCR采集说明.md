# 游戏候选自动采集（Windows）

**开发中，功能不稳定。** 识别与自动操作可能失败，请核对结果；需要停止时按 Esc。此功能不影响手动添加球员和阵容计算。

## 使用顺序

1. 在软件的比赛模式设置正确的 11 个首发位置、7 个替补，以及预备队数量。
2. 打开微信里的超迷足球，进入阵容调整页。窗口保持可见，不要最小化。
   游戏实测限制：**阵容 18 人未翻卡时，预备队候选无法打开**。默认开启临时选人：每格读完五名候选后确认一人，先完成首发和替补，再进入预备队。
3. 点击软件顶部“游戏采集”，然后“在屏幕上框选区域”。软件隐藏后，直接在整个屏幕上拖框选中游戏内容，松开鼠标确认，**不要包含微信顶部白色标题栏**。确认后才截取选区并返回软件；Esc 或右键取消，保留原区域和标记。两分钟无操作会自动取消。
4. 点击“标记首发和替补”，按列表提示点击截图上的每张卡片。首发序号以软件比赛模式为准，不要求从左到右；标记的是该位置的卡片中心。
5. 点击“标记预备队”，标记各预备队卡片。超过一屏时，填写向下滚动次数，再重新取预备队截图并标记该页的位置。
6. 点击“开始自动采集”。软件隐藏并将游戏置前，逐位置查看五名球员。采集期间不要使用鼠标、切换窗口或改变游戏大小。
7. 屏幕显示“正在自动操作，Esc 退出”。**Esc 或 Ctrl + Alt + F8 随时停止**，完成当前识别后返回软件并保留断点。切换到其他窗口、窗口移动或点击位置被遮挡也会停止。
8. 全部资料完整且无待核对项时自动导入。存在待核对信息则停在校对页，修改错误并勾选确认，再点击“确认并导入比赛模式”。默认勾选“导入后立即搜索”，导入成功后直接运行当前比赛算法和参数。

坐标会保存供下次使用。重新框选区域后需要重新标记位置；改变游戏阵型或缩放时也应重新校准。

默认勾选“配置未变时从断点继续”。中断后再次点击开始，会检查区域、位置配置、资料库和游戏窗口；符合条件时跳过完整读取的球员和已完成的位置，重读中断时未读完整的那名球员。会先从详情、球队或组合页返回，再打开原位置；当前候选名单变化则停止。改变采集配置或资料会从头开始并归档旧草稿；取消该选项可强制重采。游戏换了新一轮时应取消续采，避免复用上一轮记录。v1.1.4 及更早版本草稿不支持续采。

“详情额外等待”默认为 8 秒，可设为 0–30 秒；详情出现即继续，不需要每次等满。等待参数调整不影响断点。浮动提示不抢焦点、不接收鼠标操作，截图与点击瞬间会短暂隐藏，防止遮住游戏。

如果校准提示无法激活游戏：再次点击标记按钮，软件隐藏后，在 12 秒内点击游戏顶部白色标题栏，不要拖动窗口。Windows 可能拒绝自动置前，新版会等待手动激活。校准期间禁止重复启动；失败时保留当前截图所属页面与标记。采集中失去焦点仍会停止。

## 自动操作顺序

每个位置依次执行：

- 阵容／预备队页面 → 点击已标记卡片 → 检查“选择一名球员”窗口。
- 对五名候选逐个点击右上角感叹号，进入详情。
- 从详情页读取姓名、评分、国籍和可踢位置。评分使用局部放大与英文数字识别，读不准时保留待校对标记，不猜分数。
- 已在资料库中的人复用球队与组合；评分不同则作为同一人的新评分版本。
- 新球员点击俱乐部查看入口，读取列表并向下滚动。滚轮无变化时改用拖动列表，连续三次读取相同内容时结束；最多 20 屏，超过则标记未完整读取。
- 新球员打开“球员组合”，读取组合名、三位成员和成员位置，滚动去重。同一组合的成员即使不在球员库也可以保存。
- 返回候选窗口，再读取下一名。五名读完临时选择一名不重复、符合首发位置的球员，点击弹窗中央的“确认”，继续下个位置。关闭“读取后临时选人”时仍仅采集。

每次点击前后都检查页面；超时或状态不符就停止。**不会点击“锁定阵容”，也未实现跨位置调换最终阵容**。临时选人优先选较高评分，只用于解锁后续采集，并非搜索结果。候选全部与此前临时选人重复时停止并保留草稿，需调整已选球员后重新采集。

## 两个 L.马丁内斯

- 详情／组合中写 L.马丁内斯且位置含中锋、不含后卫：映射到资料库的 **劳塔罗**。
- 位置含中后卫、左后卫或右后卫且不含中锋：保留 **L.马丁内斯**。
- 无位置、同时读到中锋与后卫，或资料库存在多个同名身份：标记歧义，不自动合并。

## 保存与校对

采集过程中不修改资料库；全量结果通过校验后导入。采集前自动备份当前资料，过程中逐位置保存草稿到 `%APPDATA%\PitchLab\automation`。导入时保留现有库，合并新评分版本、球队和组合，并更新比赛候选。

新球队和新组合需要校对。OCR 没有可靠的逐字置信度，未读全的组合不能直接入库，可以补全或选择不导入该条。详情页评分样式或游戏 UI 改变后可能需要调整识别区域。

使用 Windows 自带的本地 OCR，不上传游戏截图。需要安装简体中文 OCR 语言组件；英文 OCR 可帮助识别评分数字。
