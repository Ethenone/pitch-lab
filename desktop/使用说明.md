# 绿茵阵容实验室 · Windows 桌面版

双击 `PitchLab-Windows-x64.exe`（v1.1.8）即可使用，无须安装 Node.js、Python，也不需要启动网页服务器。首次打开会载入内置球员资料，全部计算可离线完成。

内置资料已更新为 2026-11-14 版本：619 名球员、938 个评分版本、373 个组合。已有用户点击顶部“更新内置资料”→“合并导入”，保留个人修改和候选名单。窗口标题会显示软件版本。

比赛模式默认并推荐使用“目标引导分层搜索”，搜索时长 120 秒。可在“算法与搜索参数”中调整，已保存的自定义设置会保留。普通模式仍使用模拟退火。

球员搜索支持中文句号“。”与英文句点“.”互相匹配，适用于资料库和两种模式的候选搜索。

本版修正球队化学反应：同一时间只计最高的一项球队加成，不再叠加多个球队；普通模式、比赛模式和结果明细均适用。

**OCR 功能开发中，功能不稳定。** 自动识别和操作可能失败，请核对结果；按 Esc 可停止。阵容计算和手动管理资料可正常独立使用。

- 原有球员库、普通模式、比赛模式、算法设置、化学反应和分析页面均可使用。
- 修改自动保存在 `%APPDATA%\PitchLab`，移动或替换软件文件不会清空资料。
- 网页与软件的资料独立保存。迁移时先在网页“导出资料”，再在软件“导入资料”，选择合并或替换。
- “导出资料”可选择 JSON 文件保存位置；建议定期备份，换电脑时可导入恢复。
- 菜单“视图”支持缩放和全屏；“文件 → 打开数据文件夹”可查看本机数据目录。

顶部“游戏采集”入口：框选游戏区域、标记位置后，按首发、替补、预备队顺序读取并临时确认选人，资料导入后立即搜索。不会锁定阵容。按 Ctrl + Alt + F8 停止。具体流程见同目录的《OCR采集说明.md》。
